# BH Digital Studio — Multilingual version

The project now supports French (FR), English (EN), and Arabic (ع).

- Language switcher is available in the navbar.
- The selected language is saved in localStorage.
- Arabic automatically enables RTL direction.
- No extra npm dependency was added.

Run:
1. npm install
2. npm run dev

The main translation files are in `src/i18n/translations.js` and `src/i18n/LanguageContext.jsx`.
